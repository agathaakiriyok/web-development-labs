# Hermitage Museum — Interactive Website

Сайт Государственного Эрмитажа, разработанный с использованием чистого HTML, CSS и JavaScript (без фреймворков).

## Deployed on Render: https://agathaakiriyok.onrender.com

## Описание

Интерактивный веб-сайт музея, позволяющий пользователям:

- Просматривать информацию о музее, залах и расписании
- Смотреть галерею картин в виде слайдера
- Изучать предстоящие выставки
- Оформлять билеты онлайн через форму
- Оставлять и редактировать отзывы
- Загружать данные посетителей через внешний API

## Стек технологий

`HTML5` `CSS3` `JavaScript (ES6+)` `Fetch API` `localStorage` `HTML Templates`

## Реализованный функционал

| Функция | Описание |
|---|---|
| Галерея-слайдер | Навигация по картинам с кнопками вперёд/назад |
| Форма билетов | Выбор типа билета (стандартный, льготный, экскурсионный) |
| Отзывы (CRUD) | Добавление, отображение и редактирование отзывов с сохранением в `localStorage` |
| Загрузка через API | Асинхронный `fetch` к JSONPlaceholder API с лоадером и обработкой ошибок |
| Валидация форм | Клиентская проверка полей (длина имени, формат email, длина сообщения) |
| Активная навигация | Автоматическая подсветка текущей страницы в меню |
| Замер производительности | Отображение времени загрузки страницы через `performance.now()` |
| HTML-шаблоны | Рендеринг динамического контента через `<template>` и `cloneNode` |

